# Helmet Heads wall map pipeline

Renders the club riding area of Cayce, SC (bbox in `../map-area-corners.txt`)
for a ~48×48 in wall print. Spec: `../docs/superpowers/specs/2026-07-03-print-map-design.md`.

## Phase 1 — style previews

Setup (once):

    uv sync
    uv run playwright install chromium

Render all previews:

    uv run python scripts/stitch_tiles.py        # osm-carto, cyclosm, osm-carto+cyclosm-lite composite
    uv run python scripts/render_maplibre.py     # positron, bright, liberty
    uv run python scripts/render_prettymaps.py   # artistic

Then open `compare.html` in a browser.

Bonus reference render: submit the bbox at https://print.get-map.org (MapOSMatic)
and drop the PDF into `previews/` manually.

Data/tiles © OpenStreetMap contributors (ODbL). Preview tiles courtesy of
OSMF (osm-carto), CyclOSM/OSM France, and OpenFreeMap — previews are for
internal style comparison, not redistribution.

## Phase 2 — print-resolution rendering

Requires Docker (for the render stack) and `uv` on the host (the render/composite
helpers call `uv run`). From `render/`:

    docker compose build tools && docker compose up -d db
    ./checkout-styles.sh   # osm-carto (pinned tag) + cyclosm master/lite
    ./clip.sh              # expects ~/Downloads/south-carolina-260703.osm.pbf
    ./import.sh            # both databases
    ./build-osm-carto.sh   # external data (slow first run) + fonts + carto compile
    ./build-cyclosm.sh     # patch + shapefiles + carto compile, both variants
    ./render-full.sh       # 14400px renders + vector PDFs

Then from `map/`:

    uv run python scripts/composite_print.py   # base + overlay -> render/out/full-composite.png
    uv run python scripts/letter_crop.py       # true-scale 8x10.5in test crop around school

Print `render/out/letter-test.png` at **Actual Size** (no scaling) to judge
label legibility before ordering wall print. `./audit-bike-infra.sh`
reports the area's cycling infrastructure mapped in OSM.

## Phase 3 — poster (the final print deliverable)

Composes the finished 48×48in poster: title band, Helmet Heads logo + wordmark,
the 50%-overlay map, school marker, legend, scale bar, north arrow, attribution.
Script-generated (SVG → PDF), reproducible. Spec: the Phase 3 section of
`../docs/superpowers/specs/2026-07-03-print-map-design.md`; design rationale:
`../docs/superpowers/plans/2026-07-05-poster-furniture.md`.

Requires Docker + `uv` (as Phase 2) plus the brand fonts. After Phase 2's
styles are built, from `render/`:

    ./get-poster-fonts.sh              # Bebas Neue + Montserrat -> render/fonts/ (once)
    docker compose build tools         # if not already built (adds rsvg-convert + fonts)
    ./render-poster.sh                 # render base + overlay at the poster bbox

Then from `map/`:

    uv run python scripts/composite_poster.py   # 50% overlay -> render/out/poster-map.png
    uv run python scripts/build_poster.py       # assemble render/out/poster.svg

Back in `render/`:

    ./build-poster.sh                  # SVG -> poster.pdf (48x48in) + poster-proof-full.png

**Deliverable:** `render/out/poster.pdf` — a true 48×48in page (verify with
`pdfinfo`/MediaBox; it must read 48in, not 150in — see the size note below).

### Adjusting the poster (where the knobs are)

Nearly everything lives in `scripts/build_poster.py`:

- **Map area / zoom** — `anchored_bbox(CAYCE_BBOX, 0.5, ...)`: the `0.5` is the
  miles trimmed off the **west + south** (NE corner anchored). Change it in BOTH
  `build_poster.py` and `render/render-poster.sh`, then re-run `render-poster.sh`
  onward. 1 mile ≈ a big chunk here — the map is only ~5.7 km wide.
- **Cycling-overlay transparency** — `OVERLAY_OPACITY` in `composite_poster.py`
  (and `composite_print.py`); 0.5 = half, so street names read through.
- **Title / subtitle / "RIDE MAP"**, **legend rows**, **school marker**,
  **scale bar**, **attribution** — all inline literal strings/blocks in
  `build_poster.py`. Colors are the brand palette constants near the top.
- **Fonts** — Bebas Neue (display) + Montserrat (body), fetched by
  `get-poster-fonts.sh`, resolved by family name via fontconfig (installed into
  the container in `build-poster.sh`). Swap families by editing both.
- **PDF page size** — the SVG root declares `width="48in" height="48in"` so the
  PDF is physically 48in. Without it, rsvg infers 150in (14400px at 96 CSS dpi).
  If you change the canvas, keep the inch declaration and re-check the MediaBox.

Only scripts/config/docs are committed; everything under `render/out/`,
`render/fonts/`, `render/checkouts/`, `render/external-data/`, `data/`,
`previews/`, `cache/` is gitignored and regenerated by the steps above.
